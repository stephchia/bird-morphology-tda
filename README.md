# Topological data analysis on the evolution of bird morphology
Code and data package for the manuscript "Birds that don't exist: niche pre-emption as a constraint on morphological evolution in the Passeroidea"

## Overview
This repository contains R code and data used to reproduce the analyses and figures in the manuscript. The project applies persistent homology (topological data analysis) to morphological trait data reconstructed through time to identify and characterize unoccupied regions ("gaps") in Passeroidea morphospace.

## Repository structure
- `scripts/` R scripts for data preparation, analysis, and figure plotting. Scripts are organized in logical order and can be run sequentially to reproduce the analyses and figures.
- `data/` Raw, processed, and intermediate data used or generated in the analyses.
- `output/` Analysis outputs and figure files generated by the scripts.

## Code file description (what to run)
- `scripts/01_clean_trait_data.R`: loads and cleans AVONET morphological trait data
- `scripts/02_run_pca.R`: performs PCA on Passeroidea, and saves PC scores for downstream analysis (generate Table S1 and Figure 2)
- `scripts/03_build_consensus_tree.R`: builds a consensus phylogenetic tree for Passeroidea from 1,000 sampled trees from the Hackett backbone
- `scripts/04_ancestral_reconstruction.R`: performs ancestral state reconstruction, simulates null trait evolution, interpolates traits over evolutionary time, and visualizes evolutionary trajectories (generate Figure S1 and S2).
- `scripts/05_persistent_homology.R`: computes persistent homology across time slices for empirical and simulated datasets using the TDA package.
- `scripts/06_plot_persistence_diagram.R`： generates persistence diagrams (Figures 3D and 3E) and combined trait space + persistence diagram plots for empirical and simulated data (Figure S6).
- `scripts/07_trace_gap_series.R`: visualize topological gaps traced across evolutionary time for empirical and simulated trait datasets (generate Figure 3).
- `scripts/08_compare_null_gaps.R`: compares the distribution of topological gaps between empirical and simulated trait evolution data (generate Figures 5A, 5B, and S5).
- `scripts/09_compare_species.R`: recover original trait values from a focal topological gap (generate Figure 4A), identify and compare non-passeroid gap occupants and passeroids near the gap (generate Tables S3 and S4, 6A, 6B, and S4).

## Input data descrition
- `data/raw/AVONET_birdtree.csv`: Morphological trait data
  - Rows: 9,993 species (in BirTree taxonomy)
  - Columns: 36 taxonomic and trait information (please refer to the original publication for full metadata)
  - Data source: AVONET dataset (Tobias et al. 2022)
- `data/raw/Tobias_etal_2016_territoriality.csv`: Territoriality trait
  - Rows: 10,329 species
  - Columns: 13 taxonomic and trait information (please refer to the original publication for full metadata)
  - Data source: Tobias et al. (2016)
- `data/raw/tree1k.rds`: random sample of 1,000 phylogenetic trees from a set of 10,000 Hackett-backbone trees from Jetz et al. (2012)
  - Format: R list containing 1,000 `phylo` objects
  - Dimensions: 1,000 trees; 9,993 tips per tree
  - Branch lengths: time-calibrated (millions of years)
  - Note: this data is generated in the script `03_build_consensus_tree.R` (sufficient to run all subsequent analyses and reproduce the results presented in the manuscript). The originla data is not included in the repository due to file size constraints.
- `data/raw/consensus_tree.rds`: a consensus tree built with 1,000 Hackett backbone trees (Jetz et al. 2012), used for visualization purpose only (Figure S4)
  - Format: a `phylo` object with 9,993 tips
  - Desccription: built with R packge phytools, using majority rule for tree topology and least squares method for edge lengths.

## Processed/intermediate data descrition
- `data/processed/trait_passeroid_raw.rds`: morphological traits of passeroid species
  - Format: R data frame
  - Row names: scientific name of the species (in BirdTree taxonomy)
  - Columns (unit): Beak.Length_Culmen (log(mm)), Beak.Length_Nares (log(mm)), Beak.Width (log(mm)), Beak.Depth (log(mm)), Tarsus.Length (log(mm)), Wing.Length (log(mm)), Secondary1 (log(mm)), Hand.Wing.Index (unitless), Tail.Length (log(mm)), Mass (log(gram))
- `data/processed/trait_non_passeroid_raw.rds`: morphological traits of non-passeroid species
  - Format: R data frame
  - Row names: scientific name of the species (in BirdTree taxonomy)
  - Columns (unit): Same as `data/processed/trait_passeroid_raw.rds`
- `data/processed/pca.rds`: principal component loadings of ten morphological traits of passeroid species
  - Format: R data frame
  - Rows: morphological traits
  - Columns (unit): PC1-PC10 (unitless)
  - Values: Principal component loadings
- `data/processed/trait_passeroid_pca.csv`: principle components of morphological traits of passeroid species
  - Rows: scientific name of the species (in BirdTree taxonomy)
  - Columns (unit): PC1, PC2, PC3, PC4 (unitless)
- `data/processed/tree1k_pas.rds`: random sample of 1,000 phylogenetic trees (`data/raw/tree1k.rds`) with only passeroid species
  - Format: R list containing 1,000 `phylo` objects
  - Dimensions: 1,000 trees; 1,378 tips per tree
  - Branch lengths: time-calibrated (millions of years)
- `data/processed/contree_pas.rds`: a consensus tree built from 1,000 passeoird phylogenetic tree (`data/processed/tree1k_pas.rds`)
  - Format: a `phylo` object (with 1,378 tips)
  - Branch lengths: time-calibrated (millions of years)
- `data/processed/anc_emp.rds`: ancestral state estimations of morphological trait values
  - Format: R data frame
  - Rows: Tips (n=1,378) and internal nodes (n=654) of the phylogeny (indexed sequentially)
  - Columns (unit): PC1, PC2, PC3, PC4 (unitless)
- `data/processed/anc_sim.rds`: simulated trait values for extent species and ancestral nodes
  - Format: R list of length 10; each element is an R data frame
  - Rows and columns: same as `data/processed/anc_emp.rds`
- `data/empirical/trait_*mya.csv`: time-sliced empirical trait values at discrete time points from 0 to 10 Mya
  - Rows: Tips (n=1,378) and internal nodes (n=654) of the phylogeny (indexed sequentially)
  - Columns (unit): PC1, PC2, PC3, PC4 (unitless)
- `data/simulate/sim*/trait_*mya.csv`: time-sliced simulated trait values at discrete time points from 0 to 10 Mya
  - Structure: 10 simulation replicates (folder `sim1/`–`sim10/`)
  - Rows and columns: same as `data/empirical/trait_*mya.csv`
- `data/empirical/tda_*mya.rds`: persistent homology results (empirical time slices) at discrete time points from 0 to 10 Mya.
  - Format: RDS file containing a `ripsDiag` output object (TDA package), including birth/death pairs and point locations.
- `data/simulate/sim*/tda_*mya.rds`: persistent homology results (simulated time slices) at discrete time points from 0 to 10 Mya
  - Structure: 10 simulation replicates (folder `sim1/`–`sim10/`)
  - Format: same as `data/empirical/tda_*mya.rds`
